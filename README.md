# Site visit Krish

A site inspection tool for Mansfield, Peveril, Lichfield and Brampton. The inspector completes the checklist and finishes the report. Netlify stores reports in Blobs and provides a unique manager link for follow-up.

## Netlify

- Publish directory: public
- Functions directory: netlify/functions
- Required package: @netlify/blobs
- The online report list is accessible to anyone who can visit the site. Individual audit details can be opened through their report IDs.
